# 仓鼠小梵 Android

一款本地运行的 Android 仓鼠桌宠，当前源码版本为 2.6。应用不包含账号、广告或数据收集功能；聊天功能只有在构建时提供 `DEEPSEEK_API_KEY` 时才会启用。

## 主要功能

- 四页现代化界面：首页、小窝、家庭、设置。
- 96 帧像素仓鼠动画，覆盖待机、行走、拖动、摸头、跳跃、跳舞、进食、入睡、睡眠、苏醒、建窝和庆祝。
- 桌面仓鼠支持单指移动、双指连续缩放（35%–280%）、长按动作菜单和轻点唤醒。
- 四种食物可从食物托盘拖到仓鼠嘴边，成功投喂后播放完整进食动作。
- 喂食与互动次数分别累计，可按明确目标建造并升级两级小窝。
- 二级小窝、饱食度和亲密度达标后可繁殖，最多拥有三只不同形象的幼崽。
- 三种像素幼崽拥有不同配色与轮廓，并按喂食、陪玩进度经历新生期、幼年期和成长期。
- 五首 CC0 循环背景音乐可自动播放、切换、调节音量或完全关闭。
- 可从桌宠长按菜单、通知栏或应用设置中随时关闭桌宠。
- 所有养成进度保存在设备本地，关闭应用后仍会保留。

## 项目结构

- `app/src/main/java/com/andrew/hamsterpet/`：Android 应用源码
- `app/src/main/res/`：精灵图、音频和界面资源
- `tools/`：本地资源生成工具
- `docs/qa/`：视觉检查素材

## 安全边界

- API Key 只从构建环境变量读取，不提交到 Git。
- 不要提交 APK、`local.properties`、签名文件、私钥或构建缓存。
- 这是个人/内部项目；若要公开发布，建议把聊天 API 改为服务端代理，并增加密钥轮换和额度控制。

## 安装

1. 在 Android 8.0 或更高版本设备上安装 APK。
2. 首次启动时允许“显示在其他应用上层”。
3. Android 13 及以上建议允许通知，以便使用通知栏关闭按钮。

## 构建

需要 JDK 17 与 Android SDK 35。执行：

```text
./gradlew assembleDebug
```

第三方音乐授权与来源见 `ATTRIBUTION.md`。
